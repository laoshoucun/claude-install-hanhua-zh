# Grok Bot 怎么用：把 Claude Code 和 Codex 接进去，手机上派活

> 原文链接：[https://www.sz003.com/codexdt/2751](https://www.sz003.com/codexdt/2751)

手机上发一句话，扭头去干别的。回来的时候云电脑那边已经跑完了，一份清单摆在对话框里，几个预览链接，哪部能交、哪部要重做，都写在里面。做 AI 内容的杨竹筠现在就这么干活。Claude Code 和 Codex 都装在云电脑里，她不碰终端，只在手机上说话。

那台云电脑是 Grok Bot 自带的。xAI 在 2026 年 8 月 11 日把它放出来做测试，桌面和手机先上，安卓 9 月初跟上。它跟聊天框不是一回事。每个 Bot 背后有一台云端电脑，带浏览器、文件系统和终端，登录你常用的那些工具，然后自己动手干活。你的电脑关掉，它还在跑。

Claude Code 和 Codex 都能写代码，跑命令，改文件，前提是安装包都装到位。问题是它们得有人管。开哪个目录，先做哪一步，做完交给谁复核，一个人盯着三个终端来回切窗口，半天就没了。所以真正缺的往往不是更能干的模型，是那个分活的人。

杨竹筠的做法是给总管写一条路由，用大白话，不写代码。规则不复杂。查资料、整理清单这种轻活，它自己办。遇到难啃的，比如改技能，跑测试，重做片子，就调云电脑上那两个工具去干。规则存在共享记忆里，新开的助手也继承同一套分工。用了一个月，她觉得持久任务和分工调度这两块最能打。

一个不够就多开。它支持两到六个拉一个群，互相交任务，不用人在中间复制上下文。她开了几个，一个查数据，一个清空间，一个管几台机器之间的同步。真要动钱，动发布，动删除，它会停下来等你点头。点过一次的，也能设成一直允许。

门槛比她想的低。10 月中旬 xAI 把 Grok Bot 并进 X 的联合订阅，起步 30 美元，往上是 100 和 200，8 美元那档不含。付费用支付宝和银联都能走，国内用户不用去折腾外币卡。

坑在额度上。每周有配额，超了按用量另算，眼下没有专门的消费上限。挂着跑一夜，第二天看用量页面就知道花了多少。

安全这块，官方自己写得很直白。同一个账号下所有助手共用一台云电脑，浏览器登录状态、文件和命令行凭证都是同一套，别拿不同助手当隔离。浏览器那部分也不算稳，碰到改版或者验证码就卡。想让它在没人看着的时候长时间跑，先拿低风险的活试。

所以别急着把三个工具全接上。先开一个，挑一件你每天都在干的杂事，整理邮件，盯一个订单，把散在各处的链接归到一起，交代给它，批准权限先全开，跑一个星期。跑顺了再加第二个，把 Claude Code 接进去。配到哪一步算够，看你哪一步最费时间。
