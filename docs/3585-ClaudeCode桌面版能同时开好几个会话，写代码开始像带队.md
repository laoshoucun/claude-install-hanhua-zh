# Claude Code 桌面版能同时开好几个会话，写代码开始像带队

> 原文链接：[https://www.laoshoucun.com/claudedt/3585](https://www.laoshoucun.com/claudedt/3585)

Claude Code 的桌面版今天更新了。

消息是从 Anthropic 官方放出来的。

一直盯着 AI工具 圈子的人，多半都刷到了。

动静不小。

一次能拉起好几个 AI对话，几件事并着跑。

谁先干完，谁先回来交结果。

界面上的会话管理也被整个重做了一遍。

环境能复用，任务能一键接着跑。

随手敲个 /btw，就能开一个新标签页单独干。

对做 AI编程 的人来说，这几乎等于换了一套工作方式。

消息传开得很快，开发者社区几乎同一时间炸了锅。

Anthropic 的工程师在社交平台上说得很直接，这几乎就是一个 v2 版本。

Claude 开始自己分身

先说这次最抓人的功能：自动创建嵌套会话。

以前想让 AI 同时干三件事，得自己手动开三个窗口。

最后还得一个个核对结果，麻烦得很。

任务一多，主线程就变成了灾难现场。前端代码和后端报错混在一起，想回溯某一步的改动，只能在屏幕前疯狂滚鼠标。

现在这套逻辑翻了篇。

你只要在主对话框里，把所有任务一次性交代出去。

当它发现这些任务可以并行，就会当场施展「影分身」。

每个子任务，单独开一个嵌套会话。

更巧的是信息的流转方式。

几个子会话在后台同时开工，各自读上下文，改代码，跑测试，谁也不碰谁。

那些几百行的终端输出，还有来回试错的中间过程，全都留在子会话里。

主对话界面不受污染。

等每个子会话干完，结果会像下属向总监汇报一样，整整齐齐汇总回主会话。

主线程从头到尾都很干净。

人不用关心中间那堆报错排查。

只要坐在主会话里，像批阅奏折一样看每个 AI 交上来的答卷。

想追细节，点进去就能穿透到最底层。

不过，AI 分头干得再欢，工程上的验收还是得有人把关。

一堆对话，人怎么盯得过来

几个 Claude 一起开工，麻烦立刻就来了。

到底该看谁。

一个还在分析代码，一个正在跑命令。另一个已经停下来等你拍板。

要是只能逐个点进去翻记录，省下来的时间又会被切换窗口吃回去。

新版把这些状态搬到了更显眼的地方。

这一步挺实在。

侧边栏能看清哪些会话正在干活，哪些需要你介入。

进了会话，实时待办清单跟着它的计划往前推。

需要你回应时，一张回顾卡片会把这轮情况概括出来。

侧边信息栏则显示任务跑在哪里，上下文是什么。

代码改了哪些地方，也一并列了出来。

除了任务执行时的并发，这次连开工前的准备都没放过。

很多全栈工程师的日常环境很复杂。

前端在一个文件夹，后端微服务在另一个文件夹。

有些长周期任务，还得丢到云上跑。

每次重启软件或者切项目，光把目录和连接配好就得折腾半天。

新版对新建会话的界面动了刀，目标就四个字：无缝接续。

最近用过的文件夹，直接摆在最显眼的位置。

不用在系统目录树里一层层翻，点一下就原地开干。

一整套复杂配置还能打包，存成一个命名好的「环境」。

好几个本地文件夹的组合，某台远程主机，都能装进去。

下次要用，一键就能把整套工作台拉起来。

既然是多会话并行，两个 AI 同时改一个文件夹里的代码，难道不会打架。

这一点也提前想好了。

启动多会话时，新版直接给了「每个文件夹独立工作树」的选项。

勾一下，它就会用 Git 的工作树给不同会话拉起各自的分支。

就这么简单。

一个会话在重构底层，另一个在修线上紧急故障。

两边在文件层面彻底隔开，再不用担心互相覆盖。

细节里藏着的巧思

为什么会说新版对自身能力有了极强的自我认知。

答案就藏在两个交互细节里。

以前的 AI 工具像算盘珠子，拨一下动一下。

新版在干活的同时，会基于当前改动主动推荐下一步。

不用打字确认，点一下就行，建议会直接作为独立会话在后台跑起来。

空输入框还会浮现灰色的提示词建议，按一下 Tab 键就能采纳。

另一个让程序员拍案叫绝的，是新增的 /btw 指令。

主线推进到一半，你难免冒出临时疑问。

比如这套鉴权的凭证默认多久过期。

这时只要敲 /btw，或者按一下快捷键。

系统立刻在独立标签页开出一条支线，完整继承主会话到此刻的所有上下文。

不用重新解释背景。

主线继续狂奔，完全不受干扰。

等疑问解开，标签页一关，主线的记录依然干干净净。

这个功能看着简单，解决的却是一个很根本的痛点：心流不该被打断。

程序员最怕的就是「上下文切换税」。

每次被打断再回到深度状态，可能要十几分钟。

/btw 让人能在不打断主流程的情况下，把临时疑问顺手解决掉。

很多时候，效率就是这么一点点省出来的。

不只这些，Claude Code 还多了一个「空闲压缩」。

一个会话长时间没人管，它会在提示词缓存快过期前，自动把上下文压一遍。

关键信息留着，用量降下来，额度也就省了。

省下来的都是真金白银。

下半场拼的是带队

这波大改说到底是把 AI 编程推到了下半场。

它正从一个「AI编程助手」，变成一张「多 Agent 协作工作台」。

手感完全不一样。

过去两年，这个赛道拼的是单点能力。

代码补全准不准，单次生成对不对，跑分高不高。

到今天，瓶颈换成了另一件事：怎么让 AI 同时推进十个模块，还不把工程搞砸。

它很清楚自己有几斤几两，知道怎么把子会话孵出来跟人配合。

这才是最难的那部分。

最要紧的变化落在人身上。

人类开发者的角色挪了位置：从自己写，变成定方向，验结果。

单线程打工的时代正在落幕。

属于每个人的「多 Agent 并行军团」，今天正式上线。
