# Claude 统一入口上线：Cowork 并入聊天框，文档和幻灯片都能在里面做完

> 原文链接：[https://www.laoshoucun.com/claudedt/3219](https://www.laoshoucun.com/claudedt/3219)

今天起，Claude 的 Cowork 和聊天框合成一个入口。

Anthropic 刚刚宣布，以后只有统一的 Claude。用户不用再纠结，这件事到底该发给谁。

随口问个小问题，找它。要写一份磨几个小时的重磅报告，也直接扔给它。

打开新版，Cowork 那套能力全在里面。文档和幻灯片在同一个地方做，设计稿也是。

最重要的是，之前攒下的历史对话没丢。技能和连接器也都在。

拿到任务后，它自己判断难度，挑选对应的能力去干。电脑一合，人走了，它接着干。

统一版会先给 Pro 和 Max，时间在未来几周。免费用户再等等。

Claude 终极合并

这次真正动刀的地方是交互方式。

过去是你问一句它答一句，电脑一合，前面聊的全清零。

麻烦出在入口太多。问事情找聊天框，复杂任务开 Cowork，做设计切走，做演示再换一个工具。

可工作不按产品分类走。一份商业分析报告，要搜资料，要算数据，要写文档，还要出演示稿和视觉稿，中间反复改上几轮。这些事天然横跨好几个能力。

很多用户反馈过同一个困扰，任务到底该归到哪个空间。Anthropic 干脆把这个选择取消了。

现在，随口丢一句模糊的小需求也行。几十页的复杂报告整篇甩过去也行。

屏幕合上之后，它在后台自己接着推进。

文档和演示稿全被塞进来

严格说 Cowork 没有消失，它承担的能力被合进主入口。

过去的模式是，聊天框负责回答问题，Cowork 负责执行复杂任务，设计模块负责视觉创作。现在统一入口自己判断该用哪一块。

交给人的判断越少，交付质量越高。这是官方的说法。

更值得看的是聊天界面本身。它变成了一个创意工作台，排版和幻灯片都能在里面完成，视觉设计也一样。

文档支持起草一页纸的策划案，也支持完整文档。写好的文档能一键转成结构清晰的幻灯片。设计稿和界面原型在同一个工作区里生成。

把文档和演示放进一个入口，对 AI办公工具 这个品类来说是一次结构性调整。

表面看是加了几个办公功能。往下看一层，它从回答窗口变成了成果空间。

以前的流程是提问，拿到文本，复制到别的软件。现在的流程是提目标，建文档，做演示，生成设计，所有内容共用同一个上下文。

交互甚至细到像素级。文档里的某行文字能直接改。幻灯片的某一页可以留批注让它重写。设计元素能选中拖拽。

弄完可以直接在里面演示，按常用格式导出，也能用一个链接把内容分享出去。

这其实是一次执行框架的重构。

举个例子。出门前问一句上周业务管道有什么进展，再补上一句，按我们一贯的格式写，标出所有延误事项，重点整理成五页幻灯片，领导层会议要用。

说不清楚的地方它会主动问。路上用手机看进度，人刚坐下报告就好了，里面还带着同事的批注，幻灯片也能直接打开。两样东西出自同一段对话，内容完全一致。

还能设成每周一自动跑。到点它自己写，不用你提醒。

三家都在抢同一个入口

OpenAI 想让 ChatGPT 当统一入口，把 Codex 并进去，聊天和代码都围着它转，研究也一样。

Anthropic 的路径更明显，让 Claude 变成一个能长期执行工作的助手。

谷歌把 Gemini 往邮箱和在线文档这些现成生态里塞。

三家的走法不同，目标差不多，都想拿下智能体时代新的系统入口。国内豆包这轮资源大整合，思路也类似。

对做 AI工具 的人来说，值得盯的是执行框架这一块。

更少按钮，更多智能

过去的软件竞争是谁功能多，谁工具全，谁入口多。

到了智能体时代可能整个反过来。最好的产品，让用户看到的选项最少。

原因不复杂。复杂性被模型吸收掉了。

用户只说一句完成这个目标。剩下调什么工具，怎么拆任务，什么时候来问，什么时候自己继续，全交给它。

大多数用户其实只用了聊天框。Cowork 和设计模块里的智能体能力一直空着。

偶尔问两句，这次变化感受不明显。要连着做完一整件事，差别就出来了。

Cowork 并进聊天框不是一次普通合并。它放出的信号是，智能体正在从特殊功能变成产品的基础架构。

以后比的不只是模型能力。谁能让同一个模型真正走进工作流程，谁就多一分胜算。

想试的人先看自己的订阅档位。统一版先给 Pro 和 Max，免费用户排在后面。官方博客里有完整说明。
